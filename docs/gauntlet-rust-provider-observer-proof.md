# Rust fixed-route provider metadata observer

The Python runner's `observe_provider` reads only `/v1/models` and `/v1/benchmark-quota` through direct HTTP at the local model route, caps each body at 65,536 bytes and verifies the advertised model plus idle quota adapter against outside pins. The separate `gauntlet-provider-observer` crate adds a read-only Rust transport for those two GETs. The destination is hardcoded to `192.168.5.2` with only the previously frozen 8001/8002 ports. It neither follows redirects nor exposes an arbitrary URL, path or HTTP method. Its response parser bounds headers, decoded body and chunk count, refuses ambiguous framing, and feeds strictly decoded JSON into the existing pure model and provider-status checks.

Four library tests passed: the exact outbound GET bytes with content-length, chunked and close framing; refusal of redirects, ambiguous/oversized bodies and duplicate JSON keys; refusal of arbitrary destinations before network access; and validation of the pinned Python idle provider-status fixture with an independently supplied model ID and pins. A fifth test checks the uninstalled diagnostic's bounded, exact-field stdin request and refusal of duplicate/command fields. These local tests use in-memory HTTP streams; they are not a live provider test.

The `gauntlet-provider-shadow` binary accepts `hol-gauntlet-provider-observe-request.v1` JSON on stdin with `base_url`, `model_id` and outside `provider_pins`. It emits `hol-gauntlet-provider-observe-response.v1` with `qualification_eligible: false`. On 2026-10-20, the static ARM64 binary had SHA-256 `3e1e2272d135759d6f836cde90c4f58a5f61f908df424421d3e4008c89ffc368` on both host and the idle 16-GiB VM. A fixed-route request to port 8001 returned `status: unavailable`, `Connection refused`, and exit code 2 because the host model provider was offline. No model was loaded or queried for inference. This observer produces only diagnostic metadata; it has no inference POST, quota reservation or provider-generation attestation.

Before live use, bind its outside pins to a reviewed host provider generation and private quota journal, then prove a real exact-token request and crash-safe Python/Rust handoff. Until then the Python benchmark remains authoritative.
