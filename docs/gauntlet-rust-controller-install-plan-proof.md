# Source-derived controller install plan

The pinned Python `bootstrap.py` selects ordinary files under `ci/gauntlet`, excludes `__pycache__` and `.pyc`, and includes only a fixed allowlist under `control_plane`; it optionally adds `ci/__init__.py`. On a fresh install, `bootstrap_guest.py` writes those bytes as Root-owned mode 0444 files under mode 0755 directories. The existing Rust `TreeKind::Controller` verifier hashes a canonical path/uid/mode/file-SHA map, including the tree root.

On 2026-10-20, an independent Python calculation merged the 420-file pinned PR #5263 source manifest and the then-current 42 changes plus six additions in this integration branch. The 426-file result selected 395 installable files and 11 directories; its complete expected tree had 406 entries and digest `a62dd6dd884448f83f612c4895648577ea66e18c720942b3b7ca3a707894170e`. The new Rust `plan_controller_install` function matched that historical digest and count. Tests also show that a changed selected file or an extra installable file changes the digest; malformed paths, a missing core entry and file/directory collision refuse. A control-plane file outside the Python allowlist is excluded from a **fresh** plan, while whole-tree verification would refuse it if it appeared in an installed tree.
