# Rust private-runtime public-prompt relation

The separate `gauntlet-evidence` reader `verify_private_runtime_prompt_relation` checks one signed public task context and its reported native prompt admission. It verifies the outer runtime, builtin, MCP and task-context Ed25519 envelopes against one **outside-supplied** controller public key. It recomputes the canonical public-prompt and `UserPromptSubmit` payload digests, requires exactly one context and prompt response, checks the reported MCP actor namespaces, and matches the builtin prompt response to a native hook payload/response pair. It returns `execution_eligible: false`.

The reproducible generator `ci/gauntlet-rs/proofs/generate_private_runtime_prompt_vectors.py` extracts the public-prompt AST block from `ci/gauntlet/benchmark/private_cell_runtime_custody.py` at SHA-256 `a5f6d47ca3e87654247cf8fac1fee1d6b7e99b6e17f2da8a3d883a18b84fee0b` and the exact `_signed`/`_require` functions from `developer_product_custody.py` at SHA-256 `fa347e8cf791c21a4ce6de8d331bfbb80d80f605d0e927f672ed8475e24de21e`. Its deterministic synthetic key signs the fixture records; the generator also checks the nested MCP and builtin signatures. The fixture `private_runtime_prompt_v1.json` has SHA-256 `d60148a7277796c6fa8ce3832bc0527543376dd067af9a684bf2340a4c9aac11`. Twenty-two cases contain three accepted and 19 refused Python outcomes, including changed context, prompt, actor namespace, response, session and signatures. Rust matched every accepted/refused outcome and refusal message on native Linux ARM64 in the pinned `rust:1.88.0-slim-bookworm` image. The extra ambiguous outer JSON test passed. Rustfmt and warnings-denied Clippy passed with the same toolchain.

The fixture deliberately stubs Python `_hook` so its `allow` result is only a reported field. It does **not** execute `verify_product_audit`, `verify_private_cell_plane`, `_reviews`, `_operations` or independent kernel collection. Signed producer data can still be fabricated by an untrusted controller. No retained VM job or model inference ran for this proof. This subproof cannot qualify a deterministic control or satisfy the open private-runtime and live-verdict checklist exits.
