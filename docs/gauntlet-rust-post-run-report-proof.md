# Fixed output and ineligible report observation

The internal `spawn_prepared_controller` now requires the fixed `/var/lib/hol-gauntlet/outputs/<job-id>` entry to be absent after reserving the one-use job ID and before spawning. It refuses a pre-existing directory, regular file or symlink, including a dangling symlink. The pinned Python `ci check` implementation also requires a new output directory and creates it itself; Rust does not pre-create it. A unit test covers absent, existing-directory and dangling-symlink cases.

After a child exits, `run_prepared_controller_ineligible` first kills and drains its controller cgroup, reaps the child, stops and observes absence of its product-cell slice, verifies the worker lease, and repeats source/config/asset custody. It then reads only the fixed Root-owned `report/result.json` path. The bounded reader checks source and config pins, deterministic profile, zero model tokens with known usage, and the observed child exit. A missing or inconsistent report refuses the internal observation. An expired run does not get a report observation. The reader returns the raw report digest and producer status with `execution_eligible: false`; neither field independently scores a Guard control.

On 2026-10-20, Rust 1.88.0 ARM64 `cargo fmt --all --check`, warnings-denied Clippy for the worker and evidence crates, two targeted output-freshness tests, and three deterministic-report verifier tests passed. The final worker test binary had SHA-256 `3888bc6fb8f0035047a8ba8e9b642fa2af3a9f0113abd1aef582d2d043e0e707` on both the host and the retained 2-vCPU/16-GiB ARM VM `hol-beta-bootstrap-20261016-004`; its unprivileged run passed **30/30** worker-state tests. The full worker suite cannot pass inside this particular Docker container because its cgroup is `/`; the three cgroup-dependent cases passed on the VM. No controller or benchmark was launched by this change.

This closes only the stale-output refusal and post-run report identity subproof. The Python worker remains authoritative. An independently reviewed controller/source/install generation, live Rust dispatch, tamper/interruption tests under real product cells, independent six-control scoring, terminal receipt and model-backed campaign are still required before cutover or a PR gate.
