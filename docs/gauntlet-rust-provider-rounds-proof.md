# Provider round reconciliation proof

`gauntlet_evidence::reconcile_provider_rounds` matches the pinned Python `transport.reconcile_rounds` result on 23 frozen cases. The source is `ci/gauntlet/transport.py` SHA-256 `facd2b1ba8b1f41c5054362a95b969abce7ee7f2c217bd69366e5fa1e11aaacb` in the immutable baseline manifest. Cases cover completed rounds, zero-byte 429/5xx HTTP retries with identical request hashes, multi-retry recovery, changed requests, partial delivery, malformed status/digests/byte counts, missing response models and failures after an otherwise recoverable retry. The Rust result preserves Python's `(valid, recovered_retries)` accounting. It additionally refuses boolean delivered-byte values that Python's `False == 0` comparison would accept, and caps a supplied round list at 50,000 entries. The native ARM64 contracts job runs the parity fixture.

This is an accounting reducer over supplied JSON. It performs no HTTP request, does not independently measure delivered bytes or model usage, cannot authenticate a provider generation, and cannot qualify a model-backed campaign. An authenticated transcript, durable quota journal and independent provider deltas must be bound to these rows before a result may use them.
