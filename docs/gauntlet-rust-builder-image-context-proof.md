It then exclusively created a `builder-image-context` directory under the synthetic Root build slot and wrote only an image-ID-pinned Dockerfile plus the two trusted builder scripts. The directory and file writes use no-symlink descriptors, exact names, exclusive creation, fsync, Root ownership and digest readback. An error after directory creation leaves it in place for inspection rather than silently replaying the job.
