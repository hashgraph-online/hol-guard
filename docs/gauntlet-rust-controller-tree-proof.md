# Read-only Rust controller-tree verifier proof

The new `verify_controller_tree` reader requires a complete Root-owned, non-writable directory ancestry and one externally supplied SHA-256 for the *whole* installed controller tree. Its digest includes each path, mode, owner and regular-file hash. The `Controller` inventory mode rejects every symlink, hardlink, nonregular entry, changed file and unlisted extra byte. The read-only `gauntlet-controller-shadow` binary binds the checked tree path to the separately pinned deployment declaration and still reports `reviewed_install_anchor: false` and `execution_eligible: false`.

On 2026-10-20, a small Root-owned fixture was created at `/opt/hol-gauntlet-rust-controller-proof-20261020-001` in the idle Linux ARM VM using system `install` and `ln` commands. It contains an exact one-file `valid` tree, an `extra` tree with an additional file, a `symlink` tree and a `hardlink` tree. The Rust test executable ran **unprivileged**; no Rust code was executed as Root. Its SHA-256 was `320f4b51cfb83ea98346e336e6176993b9bbddbb43d21ae25827edc6630f9794` on both host and guest. With `GAUNTLET_ROOT_OWNED_TREE_FIXTURE=/opt/hol-gauntlet-rust-controller-proof-20261020-001`, all 19 evidence unit tests passed, including exact-tree acceptance and refusal of the four altered cases. The fixture's digest is self-observed for a mechanism test, not a reviewed install anchor.

The SHA-matched ARM64 `gauntlet-controller-shadow` diagnostic (`ba57ca2bf95130b518b3397a124fd664277ee649b002eb5810c34beeaa96d8ec`) was also run unprivileged against the retained v7 deployment with a deliberately wrong all-zero controller digest. It exited 2 at an unreadable private `__pycache__` directory. That observation is **not** a negative source verdict: the existing [file-level audit](gauntlet-rust-controller-source-audit.md) separately shows that the retained controller installation is neither exact source map. The current tree lacks an independently reviewed whole-tree install digest, and the unprivileged diagnostic cannot inspect its private cache. A fresh immutable controller build or a reviewed install manifest remains necessary before dispatch.

This verifier does not bind a future child process to the inspected bytes, verify the Python venv packages, or qualify a benchmark. It is a precondition for a reviewed Rust worker generation and remains disconnected from the running Python worker.
