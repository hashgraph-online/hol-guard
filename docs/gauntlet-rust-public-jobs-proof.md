# Passive Rust public-job projection proof

The pinned Python observer's `Agent.publish` in `ci/gauntlet/control_plane/agent.py` has SHA-256 `04aed1ecf337746caed8fbd011c59926b47b37719add867628ac6b70a5309215`. `freeze_public_jobs_v1.py` calls that method with an intercepted `atomic_json`, producing a versioned fixture without writing observer state. It covers the exact 29-field public allowlist, nested `local_build` filtering, archived-job exclusion, newest-first ordering and the 200-visible-job limit. The fixture includes private fields that must be absent and a retained `local_build.version` field that must remain public.

`gauntlet-host-state::project_public_jobs` projects already-read private job JSON to that view. It validates the whole input before returning any rows, bounds serialized output to 8 MiB and marks the projection `publication_eligible: false`. The uninstalled `gauntlet-host-shadow-public` diagnostic uses the existing private no-symlink reader and emits IDs, counts and digests, not the job contents. Its optional per-field hashes are for investigating parity differences. It takes no Python observer lease and writes no snapshot.

Three Rust tests compare the Python-frozen cases, the 200-job cap and malformed-history refusal. On 2026-10-20, the diagnostic read 116 retained private jobs and projected 26 visible and 90 archived records. Its ordered IDs and canonical SHA-256 of `{jobs, archived_jobs}` exactly matched the Python observer's existing public snapshot: `130b6cfae0ed33d3ee355021911d13ecb48bf7b3b3cbc9900d129e3129525c59` over 137,036 canonical bytes. The independent Python fixture regeneration matched the checked-in JSON. The native ARM64 Rust CI job includes these tests.

The private-job read and public-snapshot read were sequential and did not hold the observer's lock, so this result does not prove a coherent read during concurrent updates. It also does not port VM progress collection, snapshot publication, restart reconciliation or the observer lease. The Python release observer and its dashboard remain authoritative.
