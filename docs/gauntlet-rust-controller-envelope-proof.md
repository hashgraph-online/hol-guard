# Controller signed-envelope parity

`gauntlet-evidence::verify_controller_envelope` checks the two-field `{record, signature}` Ed25519 envelope used by Python `developer_product_custody._signed`. The caller supplies the 32-byte public key from outside the candidate and producer record. Rust rejects duplicate JSON keys and oversize records before verification, requires exact envelope fields and base64 signature bytes, canonicalizes the record with the pinned contract codec, and verifies its signature. A returned record is authenticated **only to that supplied key**. The function does not establish that the key was independently reviewed or that the record's SDK, kernel or product claims happened.

The fixture `python_controller_envelope_v1.json` was produced on the Linux ARM VM with Python `cryptography` 41.0.7 and the Python canonical JSON representation, using a deterministic synthetic seed. It pins `ci/gauntlet/benchmark/developer_product_custody.py` SHA-256 `fa347e8cf791c21a4ce6de8d331bfbb80d80f605d0e927f672ed8475e24de21e`, canonical record SHA-256 `bfba32cf90657ad6ffba76f3896075ba3de0d71432dbab4d3afef472f799f566`, and fixture SHA-256 `52971e266c517c2377cbe998c790ebaa16af7e92da16e632fe6ba12bd95aa1f4`. Rust checks the source pin, record bytes, public key and Python signature. Synthetic cases accept whitespace changes around the envelope and refuse an altered record, wrong or malformed outside key, extra envelope field, invalid base64, duplicate JSON key and non-string signature.

The focused three-test suite passed on macOS, in the Linux ARM container, and as a SHA-matched stripped ARM test binary on the retained VM. The VM binary SHA-256 was `905d50ec9d583e2f77f632836bb1de9462237401a5f7a881ece8d0a7883b81f2`; it ran unprivileged and was removed. The full local Rust workspace test suite also passed. This is synthetic format and cryptographic parity, not a live retained controller record or an independently anchored public key. Live controller-journal custody, SDK/kernel/product observations and independent control scoring remain open.
