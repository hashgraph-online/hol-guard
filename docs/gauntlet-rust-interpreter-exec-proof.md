# Descriptor-bound Python interpreter probe on the retained ARM VM

The Rust worker now has an uninstalled, fixed inert probe for its Root-owned Python interpreter. It first reads the existing deployment declaration and venv-to-system alias chain against caller-supplied source, raw deployment and interpreter SHA-256 pins. It retains the already-hashed executable descriptor. A short-lived child then calls Linux `execveat` with `AT_EMPTY_PATH` on that descriptor, with fixed `-I -B -c` code and a cleared, fixed environment. The code exits 73 only when `sys.prefix` equals the deployment's expected venv; exit 74 and all other exits refuse. The parent imposes a five-second deadline, rechecks the held executable after the child, and never executes controller modules or a benchmark job.

On 2026-10-20, a stripped ARM64 probe with SHA-256 `6a93264b80c559ce63faae6117340847cdf1f8fabdb14da12c9a43f810712318` matched on Mac and the idle `hol-beta-bootstrap-20261016-004` VM. It accepted the retained deployment for source `b4efd8171b06d0e13cbe12a077c376ecdc891fd1`, manifest digest `e65ab14fb8cb3d4ecb5f5eec3ff96170b2d6efd24c51e5a14d428e4427011e36`, and interpreter digest `c86f21d0da9290ece2d7d49a3f7ed52aed59cb029abdf0ea25c79634f6cbe960`. The response reported the fixed exit 73 and `sys.prefix` equal to `/opt/hol-benchmark-controller-20261013/.venv`, while `controller_files_verified`, `benchmark_executed` and `execution_eligible` remained false. The same invocation with a zero interpreter hash exited 2 before execution. A separate stripped ARM64 worker-state test binary, SHA-256 `71827d4454f0e2dbdbb02b488524d9b44dceebc3bb177d95fb70ebb5eb21385a`, passed 18/18 tests on the VM, including two descriptor-exec tests. The temporary guest binaries were removed; free space returned to 8,669,749,248 bytes.

The supplied hashes were observed on the same VM and are not reviewed external install anchors. This only proves that the `execveat` mechanism can run the held interpreter while preserving the venv. The actual deterministic `ci check` launch is not yet bound to this primitive or to the verified controller tree; no exclusive run lease, isolated cgroup, deadline/descendant cleanup, report scoring or Rust-controlled model inference is shown. A production worker must compose those controls before it can claim execution eligibility.
