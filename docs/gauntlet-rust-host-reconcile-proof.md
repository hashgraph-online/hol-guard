# Read-only Rust host/VM reconciliation proof

The Rust host slice now freezes Python `Agent.worker(job, "reconcile")` into a fixed Lima/sudo/Python request. The worker's `reconcile` branch only reads an existing terminal receipt or returns its exact missing-receipt marker. Rust bounds the response, rejects duplicate JSON keys, requires a separately supplied source/job/deployment identity for any terminal receipt, and applies Python `Agent.finish`'s state mapping as a **projection**. It never calls `Agent.finish`, modifies a host job, posts a GitHub status, or starts the benchmark.

The [Python fixture generator](../ci/gauntlet-rs/proofs/freeze_vm_reconcile.py) pins both `agent.py` and `vm_worker.py` by SHA-256 and records the exact argv, request, timeout, missing-receipt marker, and seven terminal classification/refusal cases. Four local Rust integration tests cover those vectors, malformed/oversized responses, wrong identities, nonzero model use, wrong report path, and a fake Lima executor restricted to the fixed read-only request. The isolated Linux ARM64 CI job is configured to run the same integration test.

On 2026-10-20, the uninstalled Mac diagnostic queried the retained `hol-beta-bootstrap-20261016-004` VM for historical job `4bd231e6a95d3c67`. The host record and VM producer receipt both said `passed` for source `b4efd8171b06d0e13cbe12a077c376ecdc891fd1`; Rust's Python-compatible state projection also said `passed`. A second historical build-failed job, `7027a6236c0cba9a`, returned the worker's exact no-terminal-receipt marker. Rust left its projection unavailable rather than treating that build failure as a VM benchmark result.

These reads do not form a coherent host/VM transaction. The Mac historical reader does not take the active Python observer's lease, and this Rust slice does not independently authenticate the Root-owned VM receipt bytes, report, process exit or cleanup. An idle-only host snapshot, trusted remote receipt reader, interruption test, and controlled observer handoff are still required before cutover.
