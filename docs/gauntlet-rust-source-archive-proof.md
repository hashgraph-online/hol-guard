# Passive Rust source archive proof

The host-side Python producer in `ci/gauntlet/control_plane/local_vm.py` (SHA-256 `b7f4274c4656dba13ec7b3dcc71ad96a71b0cc4dd8fccca2218041fc3db3aa20`) fetches a Git ref into a bare repository and writes `source.tar.gz` under a private `local-builds/JOB_ID` directory. The uninstalled Rust `gauntlet-host-shadow-source` is a read-only diagnostic for one retained archive. It does not fetch, extract, execute, stage or admit source.

The Rust reader accepts only a caller-supplied lowercase job ID and outside SHA-256 pin. It traverses user-owned 0700 private directories through no-symlink descriptors, requires one regular 0600 archive link, compares file and namespace metadata around a bounded read, and hashes the exact compressed bytes held in memory before parsing. It caps compressed bytes at 256 MiB, decompressed tar bytes at 640 MiB, ordinary file bytes at 512 MiB and members at 100,000. It accepts only distinct regular files or directories under `repository.git/`, refuses escaping or nonordinary paths, drains every file, and checks the gzip trailer and zero tar suffix. It never unpacks members. Every success reports `execution_eligible: false`.

On 2026-10-20 the diagnostic read retained job `e2f042a7344bbbb0` from the existing private host state. Rust and an independent Python `hashlib`/`tarfile` read agreed on SHA-256 `bedd98ab7da8ca728484799e1ef6b13c854f7fcbb31a17ebdcc469c4c772af43`, 45,439,546 compressed bytes, 14 members, eight regular files, six directories and 46,018,462 ordinary file bytes. The same two readers agreed on retained v3.48.0 release job `7b3dd7131df5fedd`: SHA-256 `5d3eeff80bedd07042a28ffdf5d0192500669b238384ca71f7a3f8631f9382be`, 44,902,294 compressed bytes, 14 members, eight files, six directories and 45,482,651 ordinary file bytes. No state file or VM was changed. Four focused Rust tests passed, including wrong pin, unsafe file, symlink, duplicate/escaping/link member and truncated gzip refusals. The full locked Rust workspace tests and Clippy passed.

This establishes internal byte and shape consistency for one historical archive, not independent provenance. The outside digest came from the retained job; this proof does not validate its trust chain, recompute the contained Git object graph and commit, check a moved release tag at admission, or verify the VM's received copy. The Rust Git fetcher, bounded Podman builder and worker execution path remain unimplemented. Keep the Python observer authoritative and the Rust binary uninstalled.
