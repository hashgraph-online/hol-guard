# Guard Cloud Review Contract

Generated from `contracts/guard-cloud-review/v2/contract.json`; do not edit this file by hand.

This contract freezes the protocol 2 review vocabulary. It does not change existing Local Guard runtime behavior.

## Glossary

- **localRequest:** The exact pending request persisted by Local Guard before the harness pauses.
- **reviewRequest:** The Cloud canonical aggregate bound to one local request and machine installation.
- **decision:** An immutable reviewer outcome recorded by Cloud for one review request.
- **deliveryCommand:** The exact signed command that transports one recorded decision to its target Local Guard.
- **localApplication:** The Local Guard result after it verifies and resolves the exact pending local request.
- **agentContinuation:** The harness-reported result after Local Guard applies a decision; it is independent of application.

## Invariants

- `decision-not-application`: A recorded Cloud decision is not evidence of local application.
- `application-not-continuation`: A successful local application is not evidence that the agent continued.
- `allow-once-exact-request`: allow_once resolves only one pending local request and cannot create reusable policy or decision memory.
- `immutable-block-not-remotely-approvable`: An immutable policy block is not a reviewable request and cannot be approved remotely.
- `policy-memory-separate-operation`: Persistent memory and policy changes require guard.review.syncPolicyMemory and separate authorization.

## Operations

- `guard.review.resolveExact`: outcomes `allow_once`, `block`.
- `guard.review.syncPolicyMemory`: outcomes none.
