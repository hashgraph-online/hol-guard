# Root observation of the Native SDK tap socket

Code pin: `d64ba53ec688708ad842fe61ec55dc921f3cf7b2` on 2026-10-21, based on the integration tree after merging `main` at `7eba6064dca90d14322c4c9d9ccc3e51a58dacbb`.

The opt-in tap child already connected to the controller's fixed Native MCP socket and checked its Root peer. The Root worker previously put the controller pin directly into the retained `native_peer` journal field. It now receives a duplicate of the child's connected Native socket through a dedicated one-use Unix `SCM_RIGHTS` channel before accepting frame data. Root checks that socket's `SO_PEERCRED` UID/GID/PID, a held pidfd, start tick and cgroup against the separately observed controller tuple, then rechecks it after parsing the child's raw frame pipe. A missing, changed or multiply supplied descriptor refuses the session; rejection closes received descriptors. The child still has its own UID-10001 and one-use tap cgroup.

Successful sessions emit `hol-gauntlet-staging-sdk-tap-summary.v2` with `native_peer_independently_observed_by_root: true`. The host pin reader and six-role evidence reader accept historical v1 only with `false` and v2 only with `true`; both remain `execution_eligible: false`. The tap journal retains the same fixed schema and Native peer fields, so old v1 evidence is not relabeled as v2.

Two separately invoked Root-only tests passed: one actual UID-10001 docs exchange with Root inspection of the handed-off socket, and one concurrent docs/mail staging exchange with a 2-session journal, v2 summary, Root-observed Native PID/start/cgroup and verified socket/cgroup tombstones. The final Root-owned test binary and stripped tap child remain separately installed for reproduction; they are diagnostics, not worker deployment artifacts.

This proof uses synthetic SDK and Native peers on the dedicated VM. It does not rerun the real six-role candidate from the earlier [live SDK tap proof](gauntlet-rust-live-sdk-tap-six-role-proof.md), install a reviewed worker/controller generation, attribute physical product effects, score Guard decisions, produce conformance or perform model inference. Root observes a socket passed by the pinned child; the trust of that handoff still depends on the exact child executable and worker source pins. Every diagnostic remains `invalid-evidence` and the PR gate remains passive.
