# Public claim corrections and retractions

This log is append-only. A corrected or retracted claim remains auditable here even after it stops rendering as active product copy.

## 2026-08-08

### RETRACTED: Windsurf support

Previous public copy listed Windsurf as a first-class supported harness. The current core support contracts contain no Windsurf adapter, and HOL product naming has migrated toward Devin. The replacement is **not** “Devin supported”: current stable and 3.0 alpha source also contain no Devin contract. Public surfaces must show Devin as unverified/unsupported until implementation and proof exist.

### CORRECTED: universal per-tool approval

Previous copy said every tool invocation requires explicit approval. Guard supports policy-driven allow, observe/watch, approval/defer, block, and unsupported outcomes depending on harness and surface. The universal statement is retracted.

### CORRECTED: scanner versus runtime

Guard performs both scan-time analysis and supported pre-action runtime enforcement. Neither should be used as a synonym for the other.
