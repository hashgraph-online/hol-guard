# HOL Guard public boilerplate

Use this wording for package registries, repository descriptions, Homebrew, partner directories, press kits, and short product summaries unless the destination imposes a smaller character limit.

## Canonical short description

> HOL Guard is AI agent runtime security with surface-specific pre-action controls and separate supply-chain inspection for MCP servers, skills, plugins, packages, and coding agents.

## Required qualification for longer copy

Guard coverage is harness- and event-specific. Policy outcomes include allow, observe, ask, block, and unsupported. Scan-time supply-chain analysis is distinct from runtime interception. Guard complements rather than replaces endpoint antivirus/EDR, SCA, dependency scanning, and secrets management.

## Compatibility

Generate compatibility from `docs/guard/public-support-manifest.v1.json`. Do not manually add a harness to boilerplate. In particular, the historical Windsurf support claim is retracted, and the naming migration toward Devin does not mean Guard currently supports Devin.
