# OMP host-call reconciliation proof

The untrusted event-accounting part of Python `evidence.reconcile` now has a pure Rust equivalent, `gauntlet_evidence::reconcile_host_calls`. The frozen source generation is `ci/gauntlet/evidence.py` SHA-256 `b76344cf9700c73abebd5d65a81d34aa28c960b591fc2bc485423afa038efe2f`, `ci/gauntlet/bridge_evidence.py` SHA-256 `b1422592828f36e489fc7fdb4217324270c79fdc3d1bf8545006bea7c11a96b7`, and `ci/gauntlet/task_arguments.py` SHA-256 `b80adbc07e9462b3ac623237ca51de4c00e121251b1fb3eaf275e93ec569a1af`. The first file changed in this integration tree, and its hash is checked against `integration-source-delta.v1.json`; the other two match the pinned baseline manifest.

`ci/gauntlet-rs/proofs/freeze_host_calls_v1.py` extracts those three exact Python function bodies without importing the benchmark runtime. Its 31 cases include complete and missing model/start/end inventories, duplicate IDs, order errors, arguments and strict completion status, OMP's task-agent and null-schema normalization, and valid/malformed SDK eval bridge pairs. The Rust test compares the complete ordered call list and sorted error classes for every case. It also refuses non-object events and arrays beyond 50,000 entries. The Linux ARM64 contracts workflow runs the same fixture test.

This proof reconciles supplied JSON only. It does not read the bounded transcript file, authenticate its producer, verify Guard-native observations or physical effects, account for provider usage, execute OMP, or establish model-backed campaign success. The later verifier must bind each event and bridge frame to an independently trusted execution before using these calls in a verdict.
